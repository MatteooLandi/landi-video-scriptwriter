# UGC Mashup

### Cos'è

Un video montato unendo tanti piccoli spezzoni di diversi video UGC.

### Perché Funziona

| Vantaggio | Spiegazione |
| ----- | ----- |
| Prova sociale massiccia | Sentire tante persone diverse che lodano il prodotto in rapida successione è estremamente persuasivo |
| Direct Response | Formato molto diretto e orientato alla vendita |
| Costo zero | Si realizza utilizzando contenuti già posseduti |
| Facile da testare | Puoi creare decine di varianti testando hook, messaggi e combinazioni diverse |
| Scalabilità | Una volta che hai il contenuto, puoi creare infinite varianti |

Principio psicologico: Social Proof Amplification — vedere molte persone diverse che approvano qualcosa attiva il bias del "bandwagon effect" (effetto carrozzone).

### Differenza tra Mashup Ads e UGC Mashup

| Elemento | Mashup Ads | UGC Mashup |
| ----- | ----- | ----- |
| Asset | Mix di UGC, b-roll, autorità, prodotto | Solo clip UGC |
| Voiceover | Sì, spesso presente | Voci originali dei creator |
| Focus | Storytelling strutturato | Social proof pura |
| Editing | Più complesso | Tagli rapidi, ritmo alto |
| Durata clip | 3-5 sec per clip | 2-4 sec per clip |

### Come Funziona

Meccanismo:

1. Raccogli 20-30 clip UGC di clienti/creator  
2. Seleziona i momenti più impattanti (3-5 sec ciascuno)  
3. Monta in sequenza rapida  
4. Ogni clip rinforza il messaggio centrale  
5. Ritmo veloce mantiene attenzione  
6. CTA finale

Regola d'oro: Varia i creator (età, genere, background) per massimizzare l'identificazione.

### Struttura UGC Mashup

Hook (clip più forte) → Clip 1: Beneficio → Clip 2: Reazione → 

Clip 3: Risultato → Clip 4: Raccomandazione → CTA

Dettaglio (45-60 secondi):

| Sezione | Durata | Contenuto |
| ----- | ----- | ----- |
| Hook | 3-5 sec | Clip più impattante (reazione forte, risultato visibile) |
| Beneficio 1 | 4-6 sec | 2-3 persone parlano dello stesso beneficio |
| Beneficio 2 | 4-6 sec | 2-3 persone parlano di un altro beneficio |
| Reazioni | 6-8 sec | 3-4 clip di reazioni genuine ("wow", "incredibile", "lo adoro") |
| Risultati | 8-10 sec | 3-4 clip di risultati specifici ("ho perso 5kg", "risparmio 2 ore") |
| Raccomandazione | 6-8 sec | 2-3 clip di raccomandazioni ("devi provarlo", "lo consiglio") |
| CTA | 3-5 sec | Overlay grafica o ultima clip con invito |

### Consigli per la Creazione

Selezione Clip:

* Scegli le clip migliori — Momenti più autentici e d'impatto  
* Varia i creator — Età, genere, background diversi \= pubblico più ampio  
* Ritmo veloce — Cambia clip ogni 2-4 secondi  
* Hook fortissimo — La prima clip deve essere la più coinvolgente  
* Audio chiaro — Ogni clip deve essere comprensibile

Editing:

* Tagli netti, no dissolvenze  
* Musica di sottofondo energica (opzionale)  
* Text overlay per enfatizzare punti chiave  
* Mantieni ritmo costante

Testing:

* Testa ordine delle clip  
* Testa durata totale (30s vs 45s vs 60s)  
* Testa hook diversi  
* Testa con/senza musica

### Varianti da Testare

Variante A: Per Beneficio

Hook → Beneficio 1 (3 clip) → Beneficio 2 (3 clip) → 

Beneficio 3 (3 clip) → Raccomandazioni → CTA

Variante B: Per Emozione

Hook → Scetticismo iniziale (2 clip) → Sorpresa (3 clip) → 

Entusiasmo (3 clip) → Raccomandazione (2 clip) → CTA

Variante C: Cronologica

Hook → Prima (problema) → Durante (uso) → Dopo (risultato) → 

Raccomandazione → CTA

### Do's & Don'ts

| ✅ DO | ❌ DON'T |
| ----- | ----- |
| Varia i creator (età, genere, stile) | Usare solo persone simili |
| Ritmo veloce (2-4 sec per clip) | Clip troppo lunghe |
| Audio chiaro e comprensibile | Audio di bassa qualità |
| Hook fortissimo (clip migliore) | Iniziare con clip debole |
| Testa combinazioni diverse | Usare sempre lo stesso ordine |
